# Better Loans Australia 🏠

Expert mortgage broking website helping Australians find the perfect home loans.

## Features

✅ **38+ Lenders** - Access to Australia's leading banks and lenders  
✅ **Fast Approvals** - Pre-approval in as little as 24 hours  
✅ **Free Service** - Completely free for borrowers  
✅ **Expert Advice** - Personalized guidance every step of the way  

## Services

- 🏡 Home Loans
- 🔄 Refinancing
- 📈 Investment Loans
- 🏢 Commercial Loans
- 💰 Mortgage Calculators

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI
- **Icons**: Lucide React
- **Analytics**: Vercel Analytics
- **Deployment**: Vercel

## Getting Started

### Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

### Build for Production

```bash
npm run build
npm start
```

## Quick Start for Development

### Edit Pages
1. Edit files in `/app` folder (e.g., `app/page.tsx` for homepage)
2. Changes save automatically
3. Visit `http://localhost:3000` to see updates

### Edit Components
1. Modify files in `/components` folder
2. Components auto-refresh
3. No page reload needed

### Edit Styles
1. Modify `app/globals.css` for global styles
2. Use Tailwind CSS classes in components
3. Changes apply instantly
